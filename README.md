# STREET MIXTAPE

Premier prototype de l'application STREET MIXTAPE.

## Fichiers
- `index.html` : structure de la page
- `style.css` : design responsive noir / rouge / cassette
- `app.js` : filtres de genres et lecteur audio local

## Tester
Ouvre `index.html` dans un navigateur.

## Publier avec GitHub Pages
Dans le dépôt GitHub :
1. Ouvre **Settings**.
2. Va dans **Pages**.
3. Dans **Build and deployment**, choisis **Deploy from a branch**.
4. Sélectionne la branche `main` et le dossier `/ (root)`.
5. Enregistre. GitHub affichera l'adresse du site une fois le déploiement terminé.

Le lecteur actuel lit un fichier audio choisi localement sur l'appareil. Il ne téléverse pas de musique sur le site.
